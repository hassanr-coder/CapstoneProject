For this capstone project I have chosen to do a library management system. The aim of this system is to track inventories for a librarian using python, allowing them to see who authors, book status, borrowed books, and if it is overdue or not. The main goal of this application is to take a complex real world process, and make it easier in a python program. It was created using the core concepts like loops and functions, error handling, strings and data structure, JSON file, all learned in this programming class.


Objectives: 
~Adding and removing
~Finding book by title name
~Tracking loans

Some Modules Used:
12-Libraries and Modules in Python - Datetime Library
9-File Handling
10-Object-Oriented Programming
11-Error Handling and Debugging

Feautures Added:
Managing Books: Add and view books using a custom Book class.
Status Toggling: A method to check books in or out.
Data Persistence: Uses a JSON file to save data between sessions.
External API: Fetches book details automatically using ISBN numbers.
Error Handling: Prevents crashes from invalid user inputs using try/except.

Instructions To Run:
1. Clone the repository
2. Make sure to have request librrary (pip) installed.
3. Run Main file name (assignment7.py) in the terminal
